# ExpenseTracker

Приложение представляет собой трекер расходов для управления личными финансами.

## Описание проекта и его функциональности

Приложение позволяет пользователю вести учет ежедневных трат и контролировать свой бюджет. 

Реализованные функциональные требования:
- Добавление новых записей о расходах с указанием суммы, описания и категории.
- Категоризация расходов с использованием предустановленного списка (Еда, Транспорт, Развлечения, Счета, Другое).
- Установка числового лимита ежемесячного бюджета.
- Автоматическое вычисление и отображение остатка бюджета (или суммы превышения) на основе текущих трат.
- Генерация отчетов посредством фильтрации списка расходов по временным периодам (Сегодня, Неделя, Месяц, Все время).
- Визуализация структуры расходов в виде кольцевой диаграммы с расчетом процентного соотношения по категориям.

## Инструкции по установке и запуску

1. Перейдите в раздел **Releases** данного репозитория.
2. Скачайте последнюю версию файла `ExpenseTracker.apk` (v 1.0).
3. Перенесите файл на ваше Android-устройство и установите его (может потребоваться разрешение на установку из неизвестных источников).

## Информация об архитектуре приложения

Архитектура проекта построена на основе принципов **Clean Architecture** и паттерна **MVVM (Model-View-ViewModel)**. Кодовая база строго разделена на три независимых слоя:

1. **Domain (Предметная область):** Содержит бизнес-правила и сущности (`Expense`, `ExpenseCategory`), а также интерфейсы репозиториев. Этот слой не имеет зависимостей от Android SDK, что обеспечивает высокую тестируемость.
2. **Data (Слой данных):** Содержит реализацию интерфейса репозитория (`InMemoryExpenseRepository`). Данные хранятся в оперативной памяти с использованием `MutableStateFlow`, что позволяет реализовать паттерн **Observer (Наблюдатель)** для реактивного обновления UI.
3. **Presentation (Слой представления):** Отвечает за отрисовку пользовательского интерфейса (Jetpack Compose) и управление состояниями экрана (`MainViewModel`). 

**Примененные паттерны проектирования:**
- **MVVM** — для разделения логики представления и визуальной части.
- **Repository** — для абстрагирования источника данных.
- **Factory** — `ViewModelFactory` используется для внедрения зависимостей в ViewModel.
- **Observer** — подписка UI на изменения данных через StateFlow.
